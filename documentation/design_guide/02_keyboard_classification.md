# Types of keyboard layouts

This section contains information about:
1. number of keys
1. split vs no-split
1. staggering

I have found the following video quite comprenhensive and well summarized:
- ["A Guide to Weird Keyboards" by Gotham Does](https://www.youtube.com/watch?v=SkNGxM4LRKQ)

As a quick summary:
- **number of keys** are expressed in percentage (where 100% is the Full Size keyboard)
  or, if the number is small, directly as number of keys.
- **staggering**: 
    - Ortholinear = 2D grid 
    - Row stagger = the standard staggering (whole rows are shifted from 2D grid)
    - Column stagger = better for ergonomics (whole columns are shifted from 2D grid)
- **split** (2 parts) vs no-split (1 part)

The linked video explain the motivation for using an splt row-staggered
approach when designing ergonomic keyboards.

Some used sentences when talking about ergonomic keyboards:
- **home position** = the keys where the fingers rest when one is not typing.
  In the standard QWERTY layout, this corresponds to the ASDFJKL;.
- **keys are distance-one away from home position** = any key can be reached by moving a finder 
from the home position by a distance equivalent to a key width or height (including diagonally).
