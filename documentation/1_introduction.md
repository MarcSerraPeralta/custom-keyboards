# Why do I want to customize and build my own keyboard?

The main reasons for building a custom keyboard are:

- ergonomics
- typing precision: avoid wrongly hitting the keys
- typing speed
- price of ergonomic keyboards

Some nice introduction videos to custom keyboards:

- ["34 keys is all you need: an ergonomic keyboard journey" by Mattia Dal Ben](https://www.youtube.com/watch?v=unMXQTSQEak)
- ["A Guide to Weird Keyboards" by Gotham Does](https://www.youtube.com/watch?v=SkNGxM4LRKQ)
